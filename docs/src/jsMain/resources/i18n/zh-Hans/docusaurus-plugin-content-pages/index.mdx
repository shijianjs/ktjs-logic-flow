<ktjs-features section-title="为什么用 Kotlin 写前端动画" tinted>

<ktjs-feature icon="lucide:workflow" title="图进图出">`render` 用类型化 builder 收节点与连线，`getGraphRawData` 用同一形状返回。</ktjs-feature>

<ktjs-feature icon="lucide:mouse-pointer-2" title="编辑表面">`addNode`、`addEdge`、`deleteElement`、选中相关方法，以及两类元素上的自定义属性。</ktjs-feature>

<ktjs-feature icon="lucide:radio" title="事件名有类型">`LogicFlowEvents` 收好 30 个事件名 —— `node:click`、`node:add`、`edge:add`、`graph:rendered`、`history:change` 等。</ktjs-feature>

<ktjs-feature icon="lucide:move" title="视口与历史">`zoom`、`fitView`、`translate`、`getTransform`，以及基于内置历史的 `undo` / `redo`。</ktjs-feature>

<ktjs-feature icon="lucide:flask-conical" title="在 Chromium 里测试">八个浏览器测试驱动真实编辑器，七个 Playwright 用例驱动演示页。</ktjs-feature>

<ktjs-feature icon="lucide:book-open" title="双语文档">每个页面都有英文与简体中文两版，并跳转到演示页与 Dokka API 文档。</ktjs-feature>

</ktjs-features>
